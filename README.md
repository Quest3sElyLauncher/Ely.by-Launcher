## Движуха Лаунчер (Dvizhuha Launcher)

**Движуха Лаунчер** — неофициальный лаунчер Minecraft с поддержкой авторизации Ely.by и Microsoft. Проект развивается как самостоятельный лаунчер с собственным оформлением, тёмной и светлой темами, управлением модами и дополнительными возможностями.

> Проект не связан официально с Mojang, Microsoft или Ely.by.

## Возможности

- Авторизация через поддерживаемые аккаунты Ely.by и Microsoft.
- Тёмная и светлая темы интерфейса.
- Управление установленными модами: мод можно временно отключить и снова включить без удаления файла.
- Кнопка управления воспроизведением гимна России.
- Звуковое сопровождение при запуске лаунчера.
- Фирменный логотип DL в цветах российского флага.

## Требования

- **Для сборки:** JDK 17 или новее.
- **Для запуска JAR:** Java Runtime подходящей версии.
- **Для сборки Windows EXE:** Windows и `jpackage` (скрипт `make-exe.bat` подготавливает необходимый JDK, если он отсутствует).

## Сборка JAR (Linux / macOS)

```bash
chmod +x build.sh
./build.sh
java -jar dvizhuha-launcher.jar
```

На Windows JAR также можно собрать из терминала, в котором доступен JDK, запустив `build.sh` через совместимую среду, например Git Bash.

## Сборка Windows EXE

1. Скачайте или клонируйте репозиторий.
2. Откройте папку проекта на Windows.
3. Запустите `make-exe.bat`.
4. Дождитесь завершения сборки и следуйте подсказкам скрипта о создании ярлыков.

Скрипт собирает Windows-приложение с помощью `jpackage`. Он может предложить создать ярлык на рабочем столе. Закрепление на панели задач может потребовать подтверждения или ручного действия в Windows.

**Важно:** `jpackage` не выполняет кросс-сборку Windows-приложения из Linux. Windows EXE нужно собирать на Windows-машине или Windows runner. На Linux можно собрать JAR командой `./build.sh`.

## Сборка через GitHub Actions

1. Откройте вкладку **Actions** репозитория.
2. Выберите workflow сборки Windows EXE.
3. При необходимости запустите его через **Run workflow**.
4. После завершения скачайте архив из раздела **Artifacts** соответствующего запуска.

Для автоматической сборки при публикации тега используйте формат имени, например `v1.1.0`.

## Моды

В окне установленных модов можно временно включать и выключать `.jar`-файлы без удаления. Для отключения файл переименовывается в `.jar.disabled`; повторное включение возвращает исходное расширение. Изменения применяются после перезапуска Minecraft.

## Звуки

Лаунчер может воспроизводить звук при запуске, а гимн России можно включать и останавливать кнопкой на верхней панели.

Перед публикацией сборок убедитесь, что у вас есть необходимые права на распространение всех добавленных аудиофайлов. Если права не подтверждены, не включайте эти файлы в публичный релиз.

## Структура проекта

- `src/launcher/` — исходный код Java и ресурсы приложения.
- `build.sh` — сборка JAR.
- `make-exe.bat` — сборка Windows-приложения.
- `.github/workflows/` — автоматизация сборки через GitHub Actions.
